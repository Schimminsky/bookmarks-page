# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project status

Early stage: a Leiningen `app` skeleton is in place (`project.clj`, `src/bookmarks_page/core.clj`, `test/bookmarks_page/core_test.clj`) with Ring/Jetty (`ring/ring-jetty-adapter`) as a dependency. `-main` still only prints "Hello, World!". The owner is writing the first Ring handler and server start themselves. `plan.md` (German) describes the scope.

Commands:
- `lein repl`: start the REPL (writes `.nrepl-port` for Conjure)
- `lein run`: run `-main`
- `lein test`: run all tests. Run a single namespace with `lein test bookmarks-page.core-test`. The template test `a-test` fails on purpose (`(is (= 0 1))`) until it's replaced.

## Purpose

A personal website for storing bookmarks, meant to clean up the browser sidebar. Planned categories (from `plan.md`): tattoo ideas, video streaming sites, audio streaming sites, manga, and a wishlist.

## How to work in this repo

- **The main goal is for the owner to learn programming.** The owner wants to write the code themselves and use Claude only when they're stuck. Claude may help with the initial project setup. After that, prefer explanations, hints, and small targeted fixes over writing whole features, unless the owner explicitly asks for more.
- **Language: Clojure, built with Leiningen (`project.clj`), not the Clojure CLI (`deps.edn`).** The Leiningen entries in `.gitignore` are therefore relevant.
- **Editor: Neovim** with Conjure (REPL evaluation, localleader `,`) and nvim-paredit. Conjure connects through `.nrepl-port`, which `lein repl` writes automatically. The cider-nrepl middleware is meant to be enabled per machine in `~/.lein/profiles.clj` (`{:user {:plugins [[cider/cider-nrepl "<version>"]]}}`), not in `project.clj`. It isn't required: Conjure also works with plain nREPL. Check whether that file exists before relying on cider-only features, since it isn't set up on every machine.
- Leiningen itself comes from the system package manager (`pacman -S leiningen`). If `lein` is missing, say so; don't try to work around it.
- `.clj-kondo/.cache/` and `.lsp/.cache/` are generated by the linter and the language server and are ignored by git. Don't commit them. For "how do I do this in Neovim" questions, the user-level `nvim-howto` skill applies.
